# 桌面邮箱登录实现详解（v2.31）

> 更新：2026-08-03。描述 `desktop/` + `/api/v1/mail` + `app_user` 的现行实现。  
> 微信侧多 Bot / 多 openid 见 API 文档 §7.3；旧天气项目 Bot 多用户见 `多用户登录实现详解.md`（遗留）。

## 1. 目标

- 桌面端用 **QQ 邮箱验证码** 登录，得到稳定 **UUID `userId`**
- 一个 `userId` 对应多个 `sessionId`（与微信模型一致）
- 未登录可试用有限轮次，再发需登录

## 2. 身份模型

| 场景 | userId | 说明 |
|------|--------|------|
| 未登录 | `desktop-user` | 占位，所有未登录桌面共用 |
| 邮箱登录后 | `app_user.user_id`（UUID） | 按邮箱唯一 |
| 微信 | openid | 与桌面账号互不打通（未做绑定） |

展示名：`用户` + 8 位数字，由 `userId` 前端派生，**不写数据库**。

## 3. 数据表

```sql
CREATE TABLE `app_user` (
  `user_id`    varchar(64)  NOT NULL,
  `email`      varchar(128) NOT NULL,
  `created_at` datetime NOT NULL DEFAULT CURRENT_TIMESTAMP,
  `updated_at` datetime NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
  PRIMARY KEY (`user_id`),
  UNIQUE KEY `uk_app_user_email` (`email`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci;
```

脚本：`wechat-ai-session/.../V4__app_user.sql`（需手动执行若环境未跑迁移）。

验证码：进程内 `ConcurrentHashMap`（课设够用），不落库。

## 4. 接口

### 4.1 发送验证码

```
POST /api/v1/mail/send-code
Body: { "email": "xxx@qq.com" }
```

成功 `Result` 200；失败 400 + 文案（格式 / 频控 / SMTP）。

### 4.2 校验并登录

```
POST /api/v1/mail/verify-code
Body: { "email": "xxx@qq.com", "code": "123456" }
Resp data: { "userId": "uuid", "email": "xxx@qq.com" }
```

流程：校验码 → `findOrCreateByEmail` → 返回 `userId`。

## 5. 前端流程

1. 右上角「登录」或免费轮次耗尽时打开浮层  
2. 邮箱 → 下一步 → 自动 `send-code` → 输入 6 位 → `verify-code`  
3. `localStorage.userId = userId`；侧栏显示展示名；可「退出登录」清掉 userId  
4. 之后聊天 / 提醒请求均带该 `userId`

### 免费轮次

- 常量 `FREE_USER_TURNS = 3`（`App.jsx`）  
- 本会话 `role===user` 条数 ≥ 3 且未登录 → 拦截发送、保留输入、弹登录  
- 登录成功且有待发送标记 → 自动 `handleSend()`

## 6. 与 session 落库的关系

| 步骤 | 行为 |
|------|------|
| 前端 `newSession()` | 只写 localStorage UUID |
| 发消息 `channel=DESKTOP` | `ensureDesktopSession(userId, sessionId)` 写入/续期 `session` |
| 登录前 | session 行可能挂 `desktop-user` |
| 登录后再发 | 若原主人为 `desktop-user`，改绑到正式 `userId` |

查库示例：

```sql
SELECT session_id, user_id, source, status, expire_at
FROM session
WHERE user_id = '登录返回的userId';
```

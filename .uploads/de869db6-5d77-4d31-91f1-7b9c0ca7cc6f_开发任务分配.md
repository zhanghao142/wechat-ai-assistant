## 3. 任务一：加 Maven 依赖

**负责**: 李  
**文件**: `wechat-ai-document/pom.xml`  
**预估**: 1 分钟  
**前置条件**: 无

### 操作

打开 `wechat-ai-document/pom.xml`，把注释的 PDFBox/POI 替换为真正的依赖：

```xml
<!-- 在 </dependencies> 之前添加 -->

<!-- PDF 解析：PDFBox -->
<dependency>
    <groupId>org.apache.pdfbox</groupId>
    <artifactId>pdfbox</artifactId>
    <version>3.0.1</version>
</dependency>

<!-- Word 解析：Apache POI -->
<dependency>
    <groupId>org.apache.poi</groupId>
    <artifactId>poi-ooxml</artifactId>
    <version>5.2.5</version>
</dependency>
```

### 验证

```bash
mvn compile -pl wechat-ai-document -am -q
# 无报错即成功
```

### 5.1 PdfParser.java

**目标**: 用 PDFBox 解析 PDF 文件为纯文本

```java
package com.wechatai.document.service.parser;

@Component
public class PdfParser implements DocumentParser {

    @Override
    public boolean supports(FileType fileType) {
        return fileType == FileType.PDF;
    }

    @Override
    public String parse(InputStream inputStream) throws Exception {
        // 用 PDFBox 的 PDDocument.load() + PDFTextStripper.getText()
        // 参考: PDFBox 官方文档
    }
}
```

**需要的类**：
- `org.apache.pdfbox.pdmodel.PDDocument`
- `org.apache.pdfbox.text.PDFTextStripper`

### 5.2 WordParser.java

**目标**: 用 Apache POI 解析 .doc/.docx 为纯文本

```java
@Component
public class WordParser implements DocumentParser {

    @Override
    public boolean supports(FileType fileType) {
        return fileType == FileType.DOC || fileType == FileType.DOCX;
    }

    @Override
    public String parse(InputStream inputStream) throws Exception {
        // .docx 用 XWPFDocument
        // .doc 用 HWPFDocument（旧版）
        // 建议先只做 .docx，.doc 放后面
    }
}
```

**需要的类**：
- `org.apache.poi.xwpf.usermodel.XWPFDocument`（.docx）
- `org.apache.poi.hwpf.HWPFDocument`（.doc，可选）

### 5.3 TxtParser.java

**目标**: 纯文本文件直接读取

```java
@Component
public class TxtParser implements DocumentParser {

    @Override
    public boolean supports(FileType fileType) {
        return fileType == FileType.TXT;
    }

    @Override
    public String parse(InputStream inputStream) throws Exception {
        // 直接 new String(inputStream.readAllBytes(), StandardCharsets.UTF_8)
    }
}
```

### 注意事项

- 每个类都要加 `@Component`，否则 Spring 扫描不到
- `parse()` 方法抛异常时外面 Worker 会捕获并更新 FAILED 状态，所以不用自己 try-catch
- PDF 解析中文一般没问题，PDFBox 默认支持 Unicode
- .doc（旧版 Word）格式较老，一期可以只做 .docx

## 6. 任务四：实现文档解析 Worker

**负责**: 伏  
**文件**: `wechat-ai-task/.../worker/DocParseWorker.java`  
**预估**: 1 小时  
**前置条件**: 任务二（RedisTaskQueue）+ 任务三（Parser）

### 当前状态

```java
public void start() {
    // TODO: 启动消费线程
}

public void stop() {
    // TODO: 停止消费线程
}
```

### 需要做的事

| 步骤 | 说明 |
|:----:|------|
| ① | 注入 `TaskQueue`、`DocumentMapper`、`List<DocumentParser>` |
| ② | `start()` 里启动一个线程，循环调 `taskQueue.pop("task:queue:doc_parse")` |
| ③ | 取到 fileId → `documentMapper.findByFileId()` 查 DB |
| ④ | 遍历 parsers，找到 `supports()` 匹配的 Parser |
| ⑤ | 打开本地文件 → `parser.parse()` → 得到文字 |
| ⑥ | `documentMapper.updateParseResult()` 更新为 PARSED |
| ⑦ | 异常 → `documentMapper.updateParseError()` 更新为 FAILED |

### 参考资料

- 图片识别功能开发指南 **第 9.5 节** 有完整代码示例（虽然写的是图片，逻辑完全一样，把 ImageParser 换成 PdfParser/WordParser/TxtParser 即可）

### 注意事项

- 使用 `@PostConstruct` 启动 Worker 线程
- 使用 `ExecutorService.newSingleThreadExecutor()` 跑循环
- 加 `@PreDestroy` 优雅关闭线程池
- Worker 跑在 `wechat-ai-task` 模块里，需要调 `wechat-ai-document` 的 Mapper——看 pom.xml 里 `task` 有没有依赖 `document`，如果没有需要加

### 需要做的事

注入 `DocumentService`，调它的 `search()` 方法（如果还没有 `search()` 方法，可以先调 `getContent()` 做全文搜索，或者用 `listBySession()` 遍历内容）：

```java
@Component
public class SearchDocumentTool {

    private final DocumentService documentService;

    public SearchDocumentTool(DocumentService documentService) {
        this.documentService = documentService;
    }

    @Tool("在已解析的文档中搜索指定关键词，返回匹配的文本段落")
    public String searchDocument(
        @P("搜索关键词") String keywords,
        @P("限定搜索范围的文档ID列表") List<String> fileIds,
        @P("最大返回结果数，默认5") Integer maxResults
    ) {
        // 调 DocumentService 搜索
        // 返回结果字符串
    }
}
```

### 注意事项

- 使用构造器注入 `DocumentService`
- `@Tool` 和 `@P` 的 description 要写清楚，LLM 靠这个判断用不用
- 返回普通 Java String 即可，框架自动转给 LLM
- `GetDocumentSummaryTool.java` 也可以一并补全

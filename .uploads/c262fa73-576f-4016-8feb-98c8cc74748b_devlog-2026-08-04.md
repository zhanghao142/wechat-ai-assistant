## 概述

今天主线是把桌面端「能跑深研」和「跑的时候看得见」做完整：并行多 Agent、进程内用量统计、联网搜索改 Node 脚本、研究报告 `generateDocument` 全链路（确认 / RAG 异步 / 附件 URL）、欢迎页新闻中文化与脏数据过滤，以及 SSE `progress` 进度文案与使用统计折线图。

**关键决定**：

1. 多步骤研究任务 → **中央只调一次** `generalAgent`，禁止拆成搜/读/存多轮或并行 filesystem。  
2. `searchInternet` **优先 Node**（`scripts/web-search.js`），Java Jsoup 兜底。  
3. `generateDocument` **先落盘返回**，RAG 索引异步，避免确认后被 Qdrant 拖死。  
4. 桌面等待态从「三点」升级为 **工具进度文案 + 三点**（`progress` 事件）。

## 二、今日开发内容

### 2.1 并行 Agent（无依赖任务）

**涉及**: `ParallelAgentBatchService`、`ToolExecuteNode`、`ChatController`、`SetRemindTool`

- 中央一次返回 ≥2 个 Agent tool_call → 线程池并行跑。  
- 仅 READ：等齐后汇总一条回复。  
- 含 WRITE：谁先停谁先确认；队头确认后续跑；全部结束后汇总。  
- 修复提醒：`"null"` 字符串、中文时间解析、过期拒绝，避免确认雪崩。

**测例**：

> 查一下上海天气，另外帮我设一个明天上午10点的提醒：开会

### 2.2 用量统计

**涉及**: `UsageMetricsService`、`DesktopUsageController`、桌面「使用统计」页

- ThreadLocal 绑定一轮；并行子线程可 `captureTurnContext` 挂回。  
- `GET /api/v1/desktop/usage?userId=&limit=` → summary + recentTurns。  
- 进程内内存，**重启清空**。  
- 晚间：下方列表改为 **Token / 耗时双折线**（纯 SVG，悬停看明细）。

### 2.3 深研链路：搜索 → 读页 → 可选截图 → 文档

**问题**：必应噪声、Agent 60s 超时、编造 URL、确认后 RAG 卡死、重复点「确认」再开 Agent、附件 404。

**修复摘要**：

| 项 | 做法 |
|----|------|
| 搜索 | Node `web-search.js` 优先；过滤百科/门户首页 |
| 超时 | `wechat.watchdog.agent-timeout-ms=240000`；Bridge 300s |
| 提示 | 只用搜索结果真链接；一次 generalAgent；截图失败跳过 |
| 保存 | generateDocument 先落盘；RAG 异步；`confirmBusySessions` |
| 截图 | 更长超时；fullPage→viewport |
| 附件 | `AItext/日期/文件名` → `/chat/generated/...`；MD 用 react-markdown 预览 |

**弱指向测例（不点名工具）**：

> 我想了解一下近五年国内快递业务量大概怎么变的……整理成一两页中文简报存成文件；有图能截就截。

中央会自行扩成强任务再交给 generalAgent。

### 2.4 欢迎页新闻

**涉及**: `DesktopNewsSuggestionService`、`GET /desktop/suggestions/news`

- 查询改为「国内热点新闻」+ `mkt=zh-CN`。  
- `isChineseText` 过滤英/日文。  
- 拒摘要里的 `[{"id":…}` 等 JSON 泄漏；无效摘要回退标题。

### 2.5 桌面进度 SSE + 三点动画

**涉及**: `DesktopProgressEmitter`、`ToolProgressTexts`、`ChatController`、`consumeSse`、`App.jsx`

```
event: progress
data: {"text":"正在搜索网页…"}
```

编排开始推「正在思考…」；工具开始/结束推文案；正式 `delta` 到来后前端清空进度。  
进度文字淡灰，右侧三点 **左→右** 依次跳动（`thinking-dots` 包一层，避免进度 label 打乱 `nth-child`）。

### 2.6 Markdown 附件预览

`.md` / `.markdown` 用 `react-markdown` + `remark-gfm` 渲染；`.txt` 仍纯文本。不执行原始 HTML。

## 三、调试过程记录

### 问题 1：搜索结果尽是百科 / 乱码政府页

| # | 现象 | 根因 | 解决 |
|---|------|------|------|
| 1 | Bing 忽略中文 query | 反爬/区域结果差 | Node 脚本 + 百度为主 |
| 2 | Agent 编造 URL | 提示未硬约束 | WebSearchSkill + generalAgent 提示：只用结果里的链接 |

### 问题 2：确认保存失败 / 连点确认

| # | 现象 | 根因 | 解决 |
|---|------|------|------|
| 1 | 超时但文件其实写完了 | 同步 RAG 卡 Qdrant | RAG 异步 |
| 2 | 又开一轮 Agent | 确认中再发「确认」当新消息 | `confirmBusySessions` |

### 问题 3：附件打不开 / MD 预览空白

| # | 现象 | 根因 | 解决 |
|---|------|------|------|
| 1 | 404 | AItext 被当成 sandbox | `/chat/generated/{date}/{name}` |
| 2 | Tauri 白屏 | `api.js` 重复 `resolveMediaUrl` | 去重 |

### 问题 4：新闻胶囊外文 / JSON 碎片

| # | 现象 | 根因 | 解决 |
|---|------|------|------|
| 1 | 英/日标题 | 无语言过滤 | 中文检测 + 国内查询 |
| 2 | `1 天前 · [{"id":136…` | 摘要选择器扫到元数据；前端优先 content | 收紧选择器 + `usableSnippet` |

### 问题 5：进度三点乱跳

进度文案插入后 `.dot:nth-child(2/3)` 选错节点 → 包进 `.thinking-dots`，延迟 0 / 0.2s / 0.4s。

### 问题 6：中文 Content-Disposition 警告

Tomcat 丢弃含汉字的 `filename=` 头（仅警告，正文仍可预览）。未阻塞功能；后续可改 RFC 5987。

## 五、架构决策记录

### 5.1 深研只走一次 generalAgent

- **时间**: 2026-08-04  
- **背景**: 中央拆成多轮/并行 filesystem → 确认打架、截图与写文件竞态  
- **决策**: 提示词强制一次 generalAgent + 原话 task；报告用 generateDocument  

### 5.2 搜索走 Node 脚本

- **背景**: 纯 Java 爬取必应不稳定  
- **决策**: `NodeScriptRunner` 白名单 + `web-search.js`；配置可关  

### 5.3 进度用 session 绑定而非 ThreadLocal

- **背景**: 并行 Agent 在线程池，ThreadLocal 传不过去  
- **决策**: `DesktopProgressEmitter` 按 `sessionId` 注册 Consumer，发射器上 synchronized

## 七、技术债务

| 项 | 优先级 | 说明 |
|----|--------|------|
| Content-Disposition RFC 5987 | 低 | 消 Tomcat 中文文件名警告 |
| 历史附件跨会话 | 中 | 重开会话 chip 可能消失 |
| navigate `domcontentloaded` | 中 | 重站 load 过慢 |
| 用量持久化 | 低 | 现仅内存 |
| image/file-stream 绑 progress | 低 | 目前主路径是 send-stream |
| 真 LLM token 流式 | 低 | 仍算完再推 |
